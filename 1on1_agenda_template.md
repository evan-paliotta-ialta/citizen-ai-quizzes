## 1. What did you build this quarter?

Ask live — there's no pre-submitted self-assessment. Prompt with: *"What have you been using Claude for since we last talked? What are you proudest of?"*

## 2. What's blocking you?

Listen for: unclear OKR linkage, missing MCP/connector access, time constraints, low confidence in a specific skill area, not sure what counts as Zone 1/2/3.

## 3. Highlander / GitHub activity check

Pull this before the call if you can.

- Commits this quarter:
- OKR(s) their work ties to:
- GitHub hygiene — closer to Level 2 (Experimenting, inconsistent) or Level 3 (Structured, repeatable playbooks, consistent commit messages)?

## 4. Capability Maturity check-in

- Where are they now: Level 2 / 3 / 4?
- What one thing would move them up a level?

## 5. Set one goal for next quarter

Concrete, single goal — not a list. Write the exact wording you'll both remember.

---

## After the call

Run `/citizen-1on1-log [citizen name]` and give it your notes (or a transcript). It adds an item to the restricted "1on1 Tracker" SharePoint list — Name, Email, Quarter, 1:1 Date, What They Built, Blocker, Capability Level, Goal Set, Prior Goal Status, Notes — and files a one-page summary doc under `Program Admin/1on1 Notes/<Name>/` in SharePoint.

`Prior Goal Status` = Done / Partial / Not Started, judged against the `Goal Set` value from that citizen's previous quarter's tracker item.
